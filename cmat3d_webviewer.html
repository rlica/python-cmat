Keyboard Shortcuts & 3D Navigation
KeyAction
TabCycle 2D projection planes (0-1 → 0-2 → 1-2)
MToggle sidebar menu open/close
Left-Click DragBox zoom in 2D matrix or 1D histogram
Right-Click DragPan 2D matrix view
Scroll Wheel (2D)Smooth zoom centered at mouse cursor
Scroll Wheel (1D)Vertical counts scale zoom; Shift+Wheel horizontal channel zoom
← → ↓ ↑ in 2DSet Left, Right, Down, Up zoom limits (Shift+Arrows pan)
← → in 1DPan channel range left / right (Shift fast pan)
↑ ↓ in 1DZoom vertical scale (↑ taller peaks, ↓ shorter peaks)
E / eExpand / Zoom into set limits
F / fFull matrix / spectrum view reset
Shift+GDraw Peak Banana Gate on 2D plane (W)
Shift+BDraw Background Banana Gate on 2D plane (B)
W / wSet 1D Coincidence Peak Gate (Limit 1, Limit 2)
X / xSet 1D Coincidence Background Gate (Limit 1, Limit 2)
Z / zCancel pending gate or clear active 1D / 2D gates
B / bIn 1D: Set background region; In 2D: Draw Background Banana
R / rSet 1D Fit / Integration Region limits
I / iIntegrate peak over Region ('R') subtracting background
V / vFit single peak at cursor (1D or 2D coincidence peak with 3D Gamba cut)
H / hFit all visible peaks on focused 1D display
P / pAutomatic 1D Peak Search on focused spectrum (CWT method)
G / gAdd / remove manual peak marker at cursor
= / +Clear all active peak fits, peak labels, and integrations
C / cCycle colormaps (Turbo, Viridis, Plasma, etc.)
L / lCycle scale: 2D (Log -> Lin -> Sqrt) or 1D (Lin / Log)
1 / 2 / 4Direct 2D scale: 1 (Linear), 2 (Sqrt), 4 (Log)
[ / ]Switch between loaded 3D matrices (prev / next)
Ctrl+OBrowse server filesystem to select and open 3D .cmat matrix
Q / qQuit viewer (stop server)
