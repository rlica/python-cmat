# python-cmat

**Python reader, decompressor, ASCII converter, and interactive Web visualizer for GASPware `.cmat` 2D gamma-gamma coincidence matrices.**

---

## 📖 Overview

`python-cmat` is a modern, standalone Python toolkit for nuclear physics data analysis. It allows you to read, decompress, convert, and interactively navigate proprietary `.cmat` 2D coincidence matrices generated by the GASPware/gsort acquisition and sorting suites.

### Key Capabilities:
- **Full `.cmat` Reverse-Engineering**: Decompresses all proprietary IVF block compression algorithms (Modes 0–32 bit-packing, Mode 33 16-bit sparse lists, Mode 34 32-bit sparse lists, Mode 37 tagged token bit-streams, Mode 41 unary run-length shift maps) directly in pure Python + NumPy.
- **CLI Matrix Converter (`cmat2amat.py`)**: Converts `.cmat` matrices into standard ASCII `.amat` files (dense 2D grid or sparse `x y count` list).
- **Interactive Web Viewer (`cmat_webviewer.py`)**:
  - Blazing fast GPU-accelerated canvas display running locally in your browser.
  - Pixel-matched rendering: fetches only as many data points as screen pixels available, with 2D max-pooling to preserve narrow gamma peaks at full zoom out.
  - **Full GASPware `cmat` Controls**: Box zoom (`Ctrl+Drag`), marker limits (`Arrow keys`), expand (`E`), full view (`F`), and pan (`Ctrl+Arrows`).
  - **Automatic 1D Sliced Projection**: Synchronized 1D histogram that dynamically projects the visible 2D region along the X or Y detector axis.
  - **Classic Binned Histogram**: Nuclear physics stepped staircase histogram with real-time mouse position inspector, calibrated energy readout (keV), and ASCII `.dat` export.

## 🖥️ Interactive Web Viewer

Launch the web viewer with a `.cmat` file:

```bash
# Launch with raw channel calibration
python3 cmat_webviewer.py GeE-symm.cmat

# Launch with energy calibration (E = a0 + a1*ch + a2*ch^2)
python3 cmat_webviewer.py GeE-symm.cmat --cal 0.5 1.0 0.0

# Specify custom port
python3 cmat_webviewer.py GeE-symm.cmat --port 8080
```

## 🔄 CLI Conversion (`cmat2amat.py`)

Convert a `.cmat` file to standard ASCII `.amat` format:

```bash
# Convert entire matrix to dense 2D ASCII grid
python3 cmat2amat.py GeE-symm.cmat GeE-symm.amat

# Convert region of interest (e.g. channels 0 to 100 on X, 0 to 100 on Y)
python3 cmat2amat.py GeE-symm.cmat GeE_roi.amat --roi 0 100 0 100

# Export sparse non-zero list: "x y counts"
python3 cmat2amat.py GeE-symm.cmat GeE_sparse.amat --format sparse
```

## 🐍 Python Library API (`cmat.py`)

```python
from cmat import CMATReader

# Load .cmat file
reader = CMATReader("GeE-symm.cmat")

# Inspect header & compression info
info = reader.get_info()
print(f"Matrix: {info['filename']}, Shape: {info['shape']}, Type: {info['matrix_type']}")

# Decompress to 2D NumPy array (int32)
matrix = reader.to_numpy()
print(f"Total counts: {matrix.sum():,}")

# Get total 1D projection
proj = reader.get_projection()

# Get 1D gated coincidence slice (channels 500 to 520)
net_spec, bg_spec, raw_spec = reader.get_gate(500, 520, axis=0)

# Export directly to ASCII
reader.export_amat("output.amat", fmt="dense")
```

## 🔬 Decompression Algorithm Reference

GASPware `.cmat` matrices are stored in an IVF container consisting of 512-byte blocks. Matrices are divided into 128 × 128 channel sub-matrices (for a symmetric 4096 × 4096 matrix, 528 lower-triangular blocks).

Each sub-block is compressed using one of 5 algorithms:
- **Mode 0–32**: Fixed bit-width channel packing (`ccomp__0_decompress`).
- **Mode 33**: 16-bit word sparse channel list (`ccomp__1_decompressW`).
- **Mode 34**: 32-bit longword sparse channel list (`ccomp__1_decompressLW`).
- **Mode 37**: Variable-length tagged token bit-stream (`ccomp__2_decompress`).
- **Mode 41**: Bit-shift-map (BSM) unary run-length compression (`ccomp__3_decompress`).
