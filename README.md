## Overview

`python-cmat` is a modern, standalone Python toolkit for nuclear physics data analysis. It allows you to read, decompress, convert, and interactively navigate proprietary 2D matrices in the `.cmat` format generated by the [GASPware](https://github.com/csteke/GASPware)/gsort acquisition and sorting suites—without requiring legacy 32-bit Fortran binaries or external C libraries.

While built as a general reader, converter, and visualizer for any 2D `.cmat` matrix, `python-cmat` includes dedicated subroutines and analysis workflows for $\gamma$-$\gamma$ coincidence matrices (such as multi-gate coincidence slicing with normalized background subtraction, and Gamba & Morhác 2D coincidence peak fitting). Future releases will expand capabilities to include handling of 3D matrices as well as time-difference spectra.

### Key Capabilities:
- **Full `.cmat` Reverse-Engineering**: Decompresses all IVF block compression algorithms (Modes 0–32 bit-packing, Mode 33 16-bit sparse, Mode 34 32-bit sparse, Mode 37 tagged tokens, Mode 41 shift maps) in pure Python + NumPy. Handles symmetric, asymmetric, and arbitrary block step sizes ($32 \times 32$, $64 \times 128$, $128 \times 128$, etc.).
- **Interactive Web Viewer**: Blazing fast GPU-accelerated HTML5 canvas with pixel-matched decimation and 2D max-pooling to preserve narrow photopeaks at full zoom.
- **Simultaneous Dual 1D Projections**: Stacked Det 1 (X sliced over visible Y) and Det 2 (Y sliced over visible X) histograms with calibrated energy readouts and ASCII `.dat` export.
- **1D & 2D Peak Fitting**: Fits Gaussian, RadWare / SAMPO exponential tail, and Hypermet EMG profiles with complete parameter covariance. Decomposes 2D coincidence peaks with Gamba & Morhác 4-component background analysis.
- **Coincidence Gating**: Multi-gate peak ($W$) and background ($X$) slicing with automatic channel normalization.
- **Multi-Matrix Differential Analysis**: Instant cycling (`[` / `]`) across multiple matrices while locking zoom, gates, and auto-refitted peak parameters.
- **Headless Spectroscopy Engine**: Automated macro scripts (`*.mac`), CLI one-liners (`-c`), and interactive REPL shell (`-i`).
- **Publication-Ready Vector PDF Export**: Outputs vector PDF figures with Times New Roman typography, calibrated keV axes, fit curves, baselines, and labeled centroids.

## Quick Start

### 1. Installation

```bash
git clone https://github.com/rlica/python-cmat.git
cd python-cmat
pip install -r requirements.txt
```
*(Requires Python 3.8+, NumPy, and SciPy).*

### 2. Launch Interactive Web Viewer

```bash
# Open a single matrix
python cmat_webviewer.py /path/to/matrix.cmat

# Or open multiple matrices for differential analysis
python cmat_webviewer.py run01.cmat run02.cmat run03.cmat
```

> [!TIP]
> **Windows Subsystem for Linux (WSL) Users**:
> To automatically open `cmat_webviewer` in your host Windows browser (with full GPU hardware acceleration), install `wslu`:
> ```bash
> sudo apt update && sudo apt install wslu
> echo 'export BROWSER=wslview' >> ~/.bashrc && source ~/.bashrc
> ```

### 3. Convert `.cmat` to ASCII (`cmat2amat.py`)

```bash
# Convert entire matrix to dense 2D ASCII grid:
python3 cmat2amat.py matrix.cmat matrix.amat

# Export sparse non-zero list: "x y counts"
python3 cmat2amat.py matrix.cmat matrix_sparse.amat --format sparse
```

### 4. Python Library API (`cmat.py`)

```python
from cmat import CMATReader

reader = CMATReader("GeE-symm.cmat")
matrix = reader.to_numpy()            # 2D NumPy array (int32)
proj_x = reader.get_projection(axis=0) # Det 1 / X total projection
net_spec, bg_spec, raw_spec = reader.get_gate(1168, 1178, axis=0) # Gated slice
```

## Essential Controls Cheat Sheet

| Action | Shortcut | Description |
|---|---|---|
| **Box Zoom** | `Click & Drag` (2D) | Zoom into selected rectangular region of the 2D matrix |
| **1D Energy Zoom** | `Click & Drag` (1D) | Zoom into selected energy range on 1D spectrum X axis |
| **Full Zoom Out** | `Double Click` (2D / 1D) | Reset view to full matrix (2D) or full spectrum (1D) |
| **1D Peak Fit** | `Ctrl + Click` (1D) or `V` | Fit 1D photopeak or multiplet (Gaussian / RadWare / Hypermet) |
| **2D Coincidence Fit**| `Ctrl + Click` (2D) or `V` | True 2D coincidence peak fit with Gamba background decomposition |
| **Peak Search** | `P` | Automatically detect candidate peaks in focused 1D spectrum |
| **Fit All Peaks** | `H` | Fit all visible candidate peaks on Peak-Aware Continuum baseline |
| **Clear Fits & Marks**| `=` or `+` | Clear all active persistent peak fits, curves, and centroid markers |
| **Coincidence Gate** | `W` (Peak) / `X` (BG) | Set peak and background coincidence gate limits on 1D spectrum |
| **Clear Gate** | `Z` | Clear active coincidence gate and restore full projection |
| **Cycle Scale** | `L` | Cycle scale of focused panel (2D: Log $\rightarrow$ Lin $\rightarrow$ Pwr; 1D: Lin $\leftrightarrow$ Log) |
| **Colormap** | `C` | Cycle colormaps (Turbo, Viridis, Plasma, Inferno, Hot, Jet, Gray) |
| **Cycle Matrix** | `[` / `]` | Switch active matrix while preserving zoom, gates, and fits |
| **Print Vector PDF** | `Print PDF` button | Export publication-quality vector PDF of 2D matrix or 1D spectrum |
| **Help Modal** | `?` | Open interactive keyboard shortcut reference |

*(See the [Complete Keyboard Shortcuts & Controls](https://github.com/rlica/python-cmat/wiki/Keyboard-Shortcuts-and-Navigation) for the full 44-action reference).*
