GASPware cmat Navigation Shortcuts

Click & Drag (2D)Box Zoom into 2D rectangle
Click & Drag (1D)Box Zoom on 1D spectrum X-axis (syncs 2D & other 1D spectrum)
Mouse Wheel (2D)Zoom In / Out centered on crosshair in equal steps
Mouse Wheel (1D)Zoom In / Out on 1D vertical counts scale (Y-axis)
Shift + Wheel (1D)Zoom In / Out on 1D spectrum X-axis (energy / channel range centered at cursor)
Double Click (2D)Fully zoom out 2D matrix and both 1D spectra (Full View)
Double Click (1D)Fully zoom out clicked 1D projection only (X range & Y scale)
Ctrl / Cmd + Click (2D)2D Coincidence Peak Fit (Gaussian/HPGe + BG & Random Subtraction)
R / rSet 1D Fit / Integration Region limits (Limit 1, Limit 2)
B / bSet 1D Background Window limits for fitting ('V') and integration ('I')
I / iIntegrate peak over Region ('R') subtracting background ('B' or boundary slope)
V / vFit peak (1D or 2D) at cursor; keeps multiple fits on display and labels centroids
H / hFit all visible peaks on focused 1D display (Peak-Aware Background)
P / pAutomatic Peak Search: 2D Coincidences on 2D Matrix (Compton-filtered), or 1D Photopeaks on focused 1D spectrum
G / gAdd / remove manual peak marker at cursor (on Det 1 or Det 2)
= (Equals) / +Clear all active peak fits (1D & 2D), peak labels, and integrations
Arrows in 1D (←, →)Pan 1D spectrum channels left / right (Shift + Arrow for 2× fast pan)
Arrows in 1D (↑, ↓)Pan / zoom 1D vertical counts scale (↑ taller peaks, ↓ shorter peaks)
Arrows in 2D (←, →, ↓, ↑)Set Left / Right (Xmin/Xmax) & Down / Up (Ymin/Ymax) limits at cursor
Shift + Arrows in 2DPan 2D matrix view in steps (uses Scroll Sensitivity)
E / eExpand / Zoom into set limits
F / fFull matrix view (zoom out)
L / lCycle scale for focused panel: 2D (Log -> Lin -> Power) or 1D (Lin / Log)
1 / 2 / 4Direct 2D scale: 1 (Linear), 2 (Power / Sqrt), 4 (Log)
C / cCycle colormaps
W / wSet Coincidence Peak Gate limits (consecutive pairs: left & right) on 1D spectrum
X / xSet Coincidence Background Gate limits (consecutive pairs: left & right) on 1D spectrum
Shift + GDraw Peak Banana ROI on 2D matrix (W, gold)
Shift + BDraw Background Banana ROI on 2D matrix (B, magenta; area-normalized subtraction)
Z / zCancel pending limit, clear active 1D coincidence gate, or clear Banana ROIs
M / mToggle left menu panel (collapse / expand)
Drag DividerAdjust width of 2D matrix vs 1D projections (double-click to reset)
[ / ] (Brackets)Switch between loaded matrices (prev / next) preserving analysis state
Ctrl + OBrowse server filesystem to select and open .cmat matrix
Q / qQuit viewer (close browser tab and stop terminal server)
Esc / ?Close Help / Cancel pending gate / Cancel pending BG region
